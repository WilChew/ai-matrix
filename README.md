🔗 **Live Deployment**: [https://wilchew.github.io/ai-matrix/](https://wilchew.github.io/ai-matrix/)

---

## ✨ Features

- **Global Top Labs Model Matrix**: Full frontier spectrum tracking across Google DeepMind (Gemini), OpenAI (ChatGPT), Anthropic (Claude), Alibaba (Qwen), and Mistral AI.
- **AI Coding Agents Layer**: Autonomous version tracking and changelog inspector for Google Antigravity Desktop, OpenAI Codex CLI, Claude Code, Alibaba Qwen Code, and Mistral Vibe.
- **Mobile-First UX (v1.1.0)**:
  - **46px Ultra-Compact Tiles**: High-density glanceable timeline nodes enabling 5-8 models visible per viewport.
  - **Single-Line Logo Filter Ribbon**: Centered squircle icon buttons with zero text wrapping.
  - **Detail Modal Popup**: Native bottom-sheet sheet with full technical specs grid and capability breakdown.
- **Instant Bilingual Support**: 100% full English and Chinese (`EN` / `中文`) runtime localization.
- **Zero External Dependencies**: Pure vanilla HTML5, CSS3, and JavaScript — ultra-fast loading with zero npm bloat.
