## ✨ Features

- **Global Top 10 Frontier AI Matrix**: Comprehensive spectrum tracking across:
  1. **Google DeepMind** (Gemini 4 / 3.5 Flash · Agent: *Google Antigravity Desktop*)
  2. **OpenAI** (GPT-6.2 / GPT-5 · Agent: *OpenAI Codex CLI*)
  3. **Anthropic** (Claude 3.7 Sonnet / Opus · Agent: *Claude Code*)
  4. **Alibaba Cloud** (Qwen 3 / 2.5 · Agent: *Qwen Code*)
  5. **Mistral AI** (Pixtral / Devstral · Agent: *Mistral Vibe*)
  6. **DeepSeek (深度求索)** (DeepSeek-V4.1 / V4-Pro / R1 · Agent: *DeepSeek Coder & Agent*)
  7. **Microsoft (微软)** (Copilot Workspace / Phi-4 · Agent: *GitHub Copilot Workspace & CLI*)
  8. **Meta AI** (LLaMA 4 / 3.3 · Agent: *Meta Code LLaMA & Dev Agent*)
  9. **xAI** (Grok 4.7 / Grok 4 · Agent: *Grok Bot*)
  10. **Zhipu AI (智谱AI)** (GLM-5 / CodeGeeX · Agent: *GLM CodeGeeX Agent*)
- **Autonomous AI Agents & Teammates Layer**: Real-time release logs, cloud virtual machines, 24/7 background routines, and terminal agent integration.
- **Mobile-First UX**:
  - **46px Ultra-Compact Tiles**: High-density glanceable timeline nodes enabling 5-8 models visible per viewport.
  - **Single-Line Logo Filter Ribbon**: Centered squircle icon buttons with zero text wrapping.
  - **Centered Detail Modal Popup**: Native bottom-sheet/modal dialog with full technical specs grid and capability breakdown.
- **Instant Bilingual Support**: 100% full English and Chinese (EN / 中文) runtime localization.
- **Zero External Dependencies**: Pure vanilla HTML5, CSS3, and JavaScript — ultra-fast loading with zero npm bloat.
