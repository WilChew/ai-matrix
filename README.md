## ✨ Features (v2.3.0 Desktop-First Focus)

- **Top 5 Desktop-Enabled AI Platforms**:
  1. **Google DeepMind** (Gemini 4 / 3.5 · Native App: *Google Antigravity Desktop*)
  2. **OpenAI** (ChatGPT GPT-4o / GPT-6 · Native App: *ChatGPT Desktop macOS/Windows* & *Codex*)
  3. **Anthropic** (Claude 3.7 / 3.5 · Native App: *Claude Desktop macOS/Windows with MCP* & *Claude Code*)
  4. **Microsoft** (Copilot / Phi-4 · Native App: *Windows Copilot* & *GitHub Copilot Workspace*)
  5. **ByteDance** (Doubao 1.5 · Native App: *Trae AI Native Desktop IDE*)
- **Pure Native Desktop Focus**: Excluded web-only, mobile-only, and CLI-only models without desktop client support.
- **24/7 Automated Sync**: GitHub Actions scheduled cron runs 4 times daily to detect new agent releases and auto-deploy.
- **Ultra-Compact Mobile UX**: Single-row 5-logo filter ribbon, 46px compact tiles, centered detail modals.
- **Bilingual**: Instant English & Chinese (`EN` / `中文`) runtime localization.
- **Zero External Dependencies**: Pure vanilla HTML5, CSS3, JavaScript.
